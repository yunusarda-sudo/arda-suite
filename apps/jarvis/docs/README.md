## Local data and evaluation output

Local assistant data, raw evaluation traces, and generated artifacts are machine-specific and excluded from source control. Hardware-specific deployment and physical acceptance records are not included in this public source bundle. Do not add personal vault data, provider transcripts, credentials, or snapshots of other projects.
